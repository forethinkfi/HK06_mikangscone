# 메모먼트 꾹꾹체

파스텔 테마는 **메모먼트 꾹꾹체**(WISEFONT)를 씁니다. 글꼴 파일은 라이선스 확인 전까지 저장소에 넣지 않았어요.

- **지금 방식**: 각자 컴퓨터에 메모먼트 꾹꾹체를 설치하면 앱과 미리보기가 그 글꼴을 씁니다. 설치하지 않은 컴퓨터에서는 Gaegu로 보여요.
  - 받는 곳: 눈누(noonnu.cc)에서 "메모먼트 꾹꾹체" 검색 → 다운로드 → 설치
- **설치 없이 모두에게 보이게 하려면**: 눈누의 라이선스에서 임베딩·재배포가 허용되는지 확인한 뒤, 이 폴더에 `MemomentKkukkukk.woff2` 를 넣으세요. 앱은 그 파일을 쓰고, `npm run preview` 도 미리보기 안에 넣어 줍니다.
