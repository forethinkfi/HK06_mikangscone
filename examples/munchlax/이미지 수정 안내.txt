먹고자 이미지 바꾸기

1. 이 폴더의 munchlax.png를 원하는 투명 PNG로 교체하세요.
2. 기본 이미지는 475 × 475 픽셀입니다. 같은 크기로 저장하면 설정 변경이 필요 없습니다.
3. 다른 크기라면 species.json의 모든 frameWidth / frameHeight를 실제 크기로 바꾸세요.
4. 화면 크기는 behavior.spriteScale로 조절합니다. 기본 0.24 = 약 114픽셀.
5. 실행 중 파일을 저장하면 자동 반영됩니다. 원본은 별도로 백업하세요.

상태별 이미지
idle = 기본 / walk = 걷기 / dragged = 잡힘 / sit = 쉬기 / sleep = 잠 / react = 클릭 반응
각 상태의 sheet를 walk.png, sleep.png처럼 바꾸면 서로 다른 그림을 사용할 수 있습니다.
기본 버전은 한 장의 그림을 기울이거나 늘여서 움직입니다. 실제 팔다리 프레임 애니메이션은 아닙니다.
motion을 지우면 그림 변형 없이 재생합니다.

스프라이트 시트
프레임은 가로 한 줄로 배치하세요. frameWidth / frameHeight는 프레임 하나 크기,
frameCount는 개수, fps는 초당 프레임입니다. 예: 4장의 128px 그림은 512 × 128 시트.
react의 loop는 false로 두세요.

이 폴더는 Git 업로드에서 제외됩니다. 이미지 권리는 원권리자에게 있으며 코드 MIT와 별개입니다.
