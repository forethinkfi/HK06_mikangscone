# 데스크톱 펫 모션 검수

1. 현재 실행되는 캐릭터 ID와 로드된 시트를 확인한다. 이미지 시트와 실제 오버레이를 함께 확인한다. 육안 확인이 어려우면 연속 프레임 또는 같은 크기의 접촉 시트를 캡처한다.
2. 좌우 이동을 각각 재생해 이동 방향과 얼굴 방향, 발 디딤 주기를 맞춰 본다. 바닥에서는 발, 벽에서는 손과 몸, 잡힌 동안에는 커서가 닿는 지점이 기준이다. 렌더 위치가 바뀌면 포인터 적중 영역과 말풍선 위치도 같이 확인한다.
3. 정지 상태에서 잡고, 천천히 놓고, 좌우 벽에 약하게 또는 세게 던져 본다. 잡힌 채 커서가 정지해 있을 때도 버둥거림이 느리고 부드러운지 본다. 왼쪽 벽 충돌, 튕겨 나온 뒤 낙하, 바닥 착지, 아파하기, 회복을 연속해서 확인한다. 약한 던지기와 강한 충돌의 포즈 및 대사가 상황에 맞는지, 포인터 캡처를 잃은 뒤에도 다시 움직이는지 확인한다.
4. 졸거나 자는 중에 예약된 대화와 새 말풍선이 나오지 않는지 확인한다. 잠에서 깨어나는 전환, 두 펫이 마주쳤다가 움직이는 상황, 커서에 대한 반복 반응도 살핀다. 두 펫이 겹쳤을 때 대상을 하나만 잡는지 본다.
5. 문제가 생긴 동작과 재현 조건을 적고 원인을 시트 매핑, 접점, 상태 전환, 이동 계산 중에서 좁힌다. 수정까지 요청받았으면 같은 동작을 다시 재생한다. 자동으로 확인한 범위와 화면에서 직접 확인한 범위를 결과에 표시한다.
