# 데스크톱 펫 외형 유지와 복구

1. 원본을 보존하고 얼굴 비율, 주요 색, 좌우 무늬, 실루엣, 소품, 렌더링 스타일을 외형 기준으로 기록한다. 원본에 없는 옆·뒷모습이 필요하면 먼저 일관된 방향 기준을 만든다. 좌우 반전 전에 비대칭 요소를 확인한다.
2. 미리보기에 원본과 문제 프레임의 앞·옆·뒤를 같은 표시 크기로 배치한다. 수면이나 충돌에서 의도한 찌그러짐과 의상·무늬·몸 크기의 변화를 구분한다. 착지와 벽 타기는 접점을 맞춘 상태에서도 비교한다.
3. 이미지 생성 도구로 복구할 때 기준 이미지, 문제 컷, 앞뒤의 정상 프레임을 함께 참고시킨다. 문제가 있는 프레임을 교체하고 동작의 순서, 촬영 방향, 접점, 표시 크기를 유지한다. 한 장짜리 컨셉 이미지도 같은 방식으로 기준을 잡는다.
4. 교체된 프레임을 투명 배경에서 재생하고 원래 동작으로 돌아올 때까지 비교한다. 시트 좌표가 달라졌으면 앱의 `species.json`을 함께 갱신하고 영향받은 모션을 확인한다.
