# 이미지로 만든 펫을 Electron 앱에 연결하기

## 현재 연결 지점

| 파일 | 확인할 내용 |
| --- | --- |
| `src/renderer/main.ts` | 실제 동반자 루프에서 포인터를 잡고 놓는 처리, 이동 방향에 따른 프레임 선택, 말풍선과 적중 영역을 갱신한다. |
| `src/renderer/BehaviorController.ts`, `PetStateMachine.ts` | 자율 상태와 입력에 의한 중단·재개를 연결한다. |
| `src/renderer/edgePath.ts` | 왼쪽 벽 → 바닥 → 오른쪽 벽의 U자 경로를 화면 좌표로 변환한다. 벽과 바닥의 전환은 이 경로를 기준으로 한다. |
| `src/renderer/AnimationController.ts`, `PetRenderer.ts` | `sourceFrames[direction][frame]` 또는 가로 스트립을 읽는다. 렌더링 위치가 달라질 때 적중 영역과 말풍선도 렌더 위치를 따르는지 확인한다. |
| `src/shared/petState.ts`, `src/shared/speciesSchema.ts` | 현재 등록된 상태와 종 설정을 확인한다. 새로운 키로 동작을 추가하려면 상태 전환, 설정 로딩, 프레임 선택까지 연결한다. |
| `personal-species/<id>/species.json` | 로컬 시험용 종 설정과 시트. 프로젝트의 `tools/start-pet.cjs`가 `personal-species` 루트를 사용한다. 기존 종에 새 프레임이 없을 때도 기본 동작이 재생되어야 한다. |

작업 시작 시 실제 실행 경로와 로컬 에셋을 다시 확인한다. 현재 방향 시트의 8행 순서는 `아래, 오른쪽 아래, 오른쪽, 오른쪽 위, 위, 왼쪽 위, 왼쪽, 왼쪽 아래`다. 오른쪽 이동은 행 2, 왼쪽 이동은 행 6, 위로 이동은 행 4다. 인덱스는 0부터 센다. 새 시트의 행 순서는 원본의 메타데이터나 그림을 보고 명시적으로 매핑한다. 화면 오른쪽·왼쪽으로 각각 이동하는 장면을 재생해 문워크가 없는지 확인한다.

새 캐릭터에는 고유한 ID를 정하고 `personal-species/<id>/`에 `species.json`과 상대 경로로 연결된 PNG 시트를 둔다. 로컬 종 선택이나 시험용 `scene.json`의 `pets` 목록을 통해 새 종을 로드한다. 현재 시작 스크립트의 기본 종과 저장된 종 선택이 시험 결과에 영향을 줄 수 있으므로 실제로 새 ID의 시트가 재생되는지 확인한다. 같은 동작 로직에 서로 다른 이미지를 연결할 수 있도록 포즈와 동작별 버릇은 종 설정에서 고른다.

## 상태와 프레임을 매핑하는 기준

| 동작 | 필요한 포즈 | 동작 시작 및 종료 |
| --- | --- | --- |
| `walk` | 좌우 옆모습 보행, 교대로 발을 짚는 반복 | 바닥에서 이동 방향과 보행 주기를 실제 속도에 맞춘다. |
| `sleep` | 눕거나 웅크린 자세, 눈을 감은 호흡 반복 | 바닥에서 휴식에 들어가고, 상호작용이나 휴식 종료 때 깬다. |
| `jump` / `fall` / `land` | 웅크림·밀어내기, 공중 자세, 착지 반동 | 짧은 점프의 높이와 착지는 런타임 좌표로 제어한다. 착지 시점에 반동을 재생하고 기존 보행 경로로 복귀한다. 바닥에서 요청된 점프와 높은 곳에서 놓였을 때의 낙하는 시작 조건이 다르다. |
| `climb` | 양쪽 벽에서 등 또는 3/4 뒤가 보이고 손발이 벽을 짚음 | 바닥 모서리에 닿으면 진입한다. 오를 때 손을 짚는 움직임과 상승을 맞추고, 정지·방향 전환에도 벽 접점을 유지한다. |
| `dragged` | 붙들린 자세와 팔다리 버둥거림 | 기존 드래그 판정 이후 자율 동작을 중단한다. 자유롭게 들어 올리는 동작이 필요하면 드래그 중 실제 화면 위치를 유지하고, 놓는 지점에서 낙하를 시작한다. |

`jump`, `fall`, `land`, `climb`은 구현 후보 이름이다. 벽을 오를 때 위쪽 `walk` 프레임을 사용하는 경우 경로 구간에 따른 애니메이션 선택을 추가할 수 있다. 화면 안쪽까지 들어 올리는 동작에서는 누르고 이동하는 동안 자유 좌표를 쓰고, 중간에 놓았을 때 그 좌표에서 떨어지도록 연결한다. `pointerup`, `pointercancel`, `lostpointercapture` 및 창 포커스 상실 때 잡기 상태가 풀리는지 점검한다.

수평 스트립은 `sheet`, `frameWidth`, `frameHeight`, `frameCount`, `fps`, `loop`로 기술한다. 방향 시트는 `sourceFrames`로 사각형을 매핑한다. 방향이나 동작마다 프레임 구성이 다르면 시트와 설정의 범위를 검증한다. 바닥에 `bottomInset`을 적용하는 현재 렌더링을 확인하고, 벽과 포인터 접점도 필요한 경우 프레임 위치 계산에 함께 연결한다. 원본의 프레임 수와 동작에 맞춰 반복 여부와 재생 시간을 정한다.

## 던지기 동작 연결

| 단계 | 포즈와 재생 조건 |
| --- | --- |
| 놓이는 순간 | 붙들린 자세에서 손이 풀리며 몸이 던진 방향으로 쏠린다. 포인터를 놓은 위치에서 이어진다. |
| 날아가기 | 몸이 진행 방향으로 기울고 손발이나 몸통이 허우적댄다. 상승과 하강의 방향 차이를 포즈로 보여준다. 공중에 있는 동안 재생한다. |
| 왼쪽 벽 충돌 | 왼쪽 경계에 처음 닿을 때 벽에 닿은 쪽의 몸이 눌리고 얼굴이 찡그려진다. 벽 접점에서 충돌 포즈를 한 번 재생한다. 오른쪽은 캐릭터의 비대칭 무늬와 소품을 확인해 방향별 컷을 고른다. |
| 벽 충돌 후 낙하 | 왼쪽 벽에서 살짝 오른쪽으로 떨어져 나오며 몸이 아래로 돌아간다. 팔다리나 몸통이 허우적대는 전용 낙하 포즈를 재생하고 바닥에 가까워지면 몸을 웅크린다. |
| 바닥 착지 | 바닥에 닿을 때 아래쪽으로 몸이 눌렸다 반동으로 살짝 펴진다. 바닥 접촉 위치를 기준으로 착지 포즈를 한 번 재생한다. |
| 아파하기 | 바닥에 멈춘 뒤 눈을 질끈 감거나, 닿았던 부위를 문지르며 잠깐 웅크린다. 강한 충돌에서 재생한다. |
| 정신 차리기 | 고개를 털고 눈을 깜빡이며 자세를 가다듬는다. 회복이 끝나면 대기하거나 다시 걷는다. |

- `main.ts`의 해제 처리, `throwMotion.ts`의 속도·충돌 계산과 `hurt` 상태가 구현되어 있으면 이를 재사용한다. 잡는 동안 자유 화면 좌표를 유지하고, 실제 `pointerup` 시 최근 포인터 위치와 시간으로 초기 속도를 구한다. 속도가 작거나 손을 멈춘 채 놓으면 일반 낙하로 이어진다. 입력 취소나 캡처 상실도 일반 해제 경로로 정리한다.
- 비행은 화면 좌표와 속도로 계산한다. 해제 속도가 지나치게 크면 제한하고 프레임 사이의 이동 구간이 경계를 통과했는지 확인해 충돌 포즈가 실제 접촉 위치에서 시작하게 한다. 아파하기 여부는 부딪친 면을 향한 충돌 직전 속도로 판단한다. 벽에서 가장 큰 충격을 받은 경우 바닥에 내려온 뒤 그 충격에 맞는 반응을 이어간다.
- 충돌 계산에서 닿은 면을 구분해 벽 충돌과 바닥 착지가 각각 해당 포즈를 시작하게 한다. 벽에서 맞은 면과 충격을 착지까지 유지해 아파하는 포즈에 반영한다. 벽에 다시 닿거나 바닥에 일찍 도착하면 실제 접촉 시점에 다음 포즈로 전환한다. 낮은 높이에서는 벽 낙하의 공중 재생 구간이 짧아질 수 있다.
- 회복이 끝나면 착지 지점에 해당하는 바닥 경로에서 자율 이동을 재개한다. 충돌·아파하기·회복처럼 한 번 재생하는 포즈의 종료를 확인하고, 충돌 중에는 말풍선이나 자율 만남 동작이 상태를 가로채지 않게 한다.
- 왼쪽 벽의 높은 곳과 바닥 가까운 곳에 각각 던져 벽 접촉·튕김·낙하·착지·아파하기·회복 순서를 확인한다. 오른쪽이나 위로 던지기, 벽 가까이에서 놓기, 천천히 놓기, 입력 취소도 시험한다. 일반 낙하에서는 평소 착지로 이어지는지 확인한다.

## 전환 동작과 캐릭터별 버릇

| 동작 | 시작 조건과 다음 동작 |
| --- | --- |
| 기지개와 하품 | 바닥에서 자연스럽게 깰 때 잠 → 눈 비비기 → 하품·기지개 → 대기 또는 걷기. 잠든 펫을 잡으면 잡기 반응으로 이어진다. |
| 발밑 내다보기 | 발밑에 공간이 있는 경로 지점에서 정지 → 가장자리를 짚고 아래 보기 → 경로를 되돌아가거나 내려가기. 화면 바닥 모서리에서는 아래로 떨어질 공간이 있는지 확인한다. |
| 벽에서 미끄러졌다 다시 잡기 | 벽을 오르는 중 가끔 한 손 미끄러짐 → 짧게 아래로 밀리며 다리 허우적대기 → 다시 벽 짚기 → 오르기. 벽 쪽 접점을 따라 움직이고 바닥에 닿으면 착지로 이어진다. |
| 착지 후 털기 | 점프나 낙하 후 바닥 접촉 → 몸이 눌렸다 펴짐 → 몸이나 엉덩이를 털기 → 대기 또는 걷기. 착지 좌표에서 털기 포즈를 재생한다. |
| 커서 눈치 보기 | 대기 중 커서가 가까워지면 시선을 돌린다. 짧은 시간에 거리가 크게 줄면 한 번 움찔하고, 커서가 멀어지면 원래 자세로 돌아간다. |
| 서로 마주치기 | 같은 경로 구간의 두 펫이 서로 접근하면 함께 멈추고 마주 본다. 한 펫만 잠깐 물러나거나 방향을 돌려 이동을 재개한다. 경로가 좁을 때는 물러날 수 있는 쪽을 고른다. |
| 먹고자의 졸기 | 바닥 보행을 마칠 때 가끔 걷기 → 앉기 → 고개가 두어 번 꾸벅임 → 수면으로 이어진다. |
| 고라파덕의 갸웃하기 | 바닥에서 대기할 때 가끔 멈춤 → 양손으로 머리 감싸기 → 고개 갸웃하기 → 대기 또는 걷기로 이어진다. |

짧은 동작은 한 번 재생하고 다음 상태로 넘어간다. 커서가 근처에 머물거나 두 펫이 나란히 있을 때 같은 반응이 연달아 재생되지 않도록 다음 접근이나 휴지 시간을 기다린다. 마주치기는 `main.ts`의 동반자 거리·말풍선 처리와 함께 확인한다. 잡기와 공중·착지 처리가 진행 중이면 자율 반응은 대기시킨다.

런타임을 수정했다면 `npm run typecheck`, `npm test`, `npm run build`를 실행한다. 실제 Windows 오버레이에서 양쪽 방향, 바닥에서 벽으로 넘어가는 자세, 높은 위치에서 놓았을 때 낙하와 착지, 놓기·취소 후 보행 복귀를 확인한다. 프레임이 없는 기존 종도 실행 경로에서 함께 확인한다.

추가 동작을 연결했다면 기상과 졸기가 수면 전후에 이어지는지, 벽을 다시 잡았을 때 위치가 튀지 않는지, 커서와 만남 반응이 반복해서 발동하지 않는지 확인한다. 두 펫이 마주쳤다가 둘 다 다시 움직이는지, 말풍선이 고개 움직임을 따라가는지도 확인한다.
