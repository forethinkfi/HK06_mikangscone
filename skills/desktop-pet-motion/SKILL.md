# 데스크톱 펫 동작 만들기

## 원본에서 동작 프레임까지

1. 일러스트나 사진 한 장으로 시작할 수 있다. 배경이 있으면 움직일 대상을 추려내고, 원본과 좌우·뒷모습을 대조할 기준 이미지를 만든다. 색, 비율, 무늬, 실루엣, 소품을 유지한다. 방향별 그림이나 시트, GIF가 있으면 재사용 가능한 컷을 먼저 확인한다. 이미지 생성이 필요하면 작업 환경의 이미지 생성 도구와 지침을 사용한다.
2. 전체 펫 제작은 대기, 좌우 걷기, 수면 중 호흡, 점프, 양쪽 벽 타기, 잡혔을 때 버둥거림, 일반 낙하·착지와 아래 전환 모션을 포함한다. 동작 보수나 일부 동작만 요청한 작업은 지정된 범위에 맞춘다. 이족·사족·날개·팔다리 없는 캐릭터 등 원본의 체형에 맞춰 포즈를 정한다. 예를 들어 발이 있는 펫은 발을 번갈아 짚고, 발이 없는 펫은 기어가거나 통통 튀는 사이클로 같은 이동 역할을 구현한다. 벽 타기와 버둥거림도 캐릭터가 실제로 벽에 붙거나 잡힌 것처럼 보이도록 몸의 접점을 바꾼다. 달리기도 요청되면 빠른 이동에 맞는 별도 사이클을 만든다.
3. 제작 원본을 보존하고, 동작별 투명 PNG 프레임을 엔진이 읽는 시트로 묶는다. 동일한 캐릭터 크기와 기준 캔버스를 유지한다. 걷기·잠은 바닥 접점, 벽 타기는 벽 쪽 손의 접점, 잡기는 커서가 붙는 접점을 기준으로 프레임을 확인한다. 걷기·오르기·점프의 화면 이동량은 앱 좌표에서 적용할 수 있도록 프레임의 이동량과 구분한다.
4. 접촉 시트와 짧은 재생 미리보기에서 빈 프레임, 잘림, 방향 뒤집힘, 반복 경계의 튐, 크기와 접점의 흔들림을 확인한다. 좌우를 반전해 재사용하려면 비대칭 무늬나 소품을 먼저 확인한다.

## 데스크톱 앱에 연결하기

기존 프로젝트의 입력 처리, 상태 전환, 경로, 렌더러, 이미지 설정을 먼저 찾는다. 포켓몬 데스크톱 펫 프로젝트에서 작업할 때는 [현재 Electron 앱 연결 가이드](references/electron-pet.md)를 읽는다.

걷기에서 벽으로 진입할 때 등이나 3/4 뒤가 보이는 오르기 자세로 바꾼다. 점프는 도약·공중·착지 구간에서 포즈와 이동 시점을 맞춘다. 포인터가 펫을 잡는 동안 자율 이동을 멈추고, 잡힌 위치를 유지한 채 짧게 버둥대거나 잠깐 멈추었다 다시 버둥댄다. 놓으면 현재 위치에서 유효한 지지면으로 복귀한다. 해제 및 취소 경로에서 입력과 자율 이동이 정상 복구되는지 검증한다.

### 던지기와 회복

잡은 채 빠르게 움직이다 놓으면 진행 방향으로 몸이 쏠리고 팔다리나 몸통이 허우적댄다. 벽이나 바닥에 닿는 순간 접촉한 쪽으로 몸이 눌리거나 움츠러든다. 벽에 맞으면 바닥으로 내려오고, 멈춘 뒤 잠깐 눈을 질끈 감거나 부딪힌 곳을 문지른다. 고개를 털고 자세를 가다듬어 다시 걸을 때까지 각 단계의 포즈를 만든다. 천천히 놓는 경우에는 일반 낙하와 착지를 재생한다.

**왼쪽 벽 충돌과 낙하**에는 전용 프레임을 만든다. 벽에 닿는 순간 왼쪽 접점에서 몸이 눌리고 얼굴이 찡그려진다. 이어 벽에서 살짝 튕겨 나오며 아래로 몸이 돌아가고, 팔다리나 몸통이 허우적대며 떨어진다. 바닥에 닿으면 몸을 웅크린 채 부딪힌 곳을 문지르고, 고개를 털며 일어난다. 벽 접촉, 벽에서 떨어지는 자세, 착지는 각각 구분해서 그린다.

### 기본 동작 사이에 넣을 모션

- **기상과 착지** — 잠에서 깨면 눈을 비비고 하품하며 기지개를 켠다. 공중에서 내려오면 바닥에 닿는 순간 몸이 살짝 눌리고, 일어나 엉덩이를 턴 다음 움직인다.
- **가장자리 행동** — 발밑이 트인 가장자리에서 멈춰 아래를 빼꼼 보고, 내려가거나 돌아선다. 벽을 오르다 한 손이 미끄러지면 다리를 허우적대고 다시 손을 짚는다.
- **커서와 다른 펫에 대한 반응** — 커서가 가까워지면 고개와 시선으로 따라보고, 빠르게 다가오면 움찔한다. 다른 펫과 마주치면 둘이 멈춰 서로를 보고 한쪽이 비켜 준다.
- **캐릭터별 버릇** — 먹고자는 걷다가 앉아서 꾸벅꾸벅 졸고 잠든다. 고라파덕은 잠깐 멈춰 양손으로 머리를 감싸고 고개를 갸웃한다. 다른 캐릭터에는 체형과 성격에 맞는 버릇을 정한다.

스프라이트만 요청받았으면 시트와 미리보기를 제공한다. 이미지 한 장으로 전체 펫을 만드는 작업은 앱에서 불러올 수 있는 시트와 `species.json`을 만들고 실제 실행 경로에서 새 펫을 확인한다. 좌우 걷기, 잠, 점프, 양쪽 벽 타기, 잡기, 일반 놓기, 던지기와 회복을 재생하고, 다른 펫이 있을 때 마주치는 모션도 확인한다. 제작한 포즈와 앱에서 실행 확인한 동작을 결과에 적는다.
