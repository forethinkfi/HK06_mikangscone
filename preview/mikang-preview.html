3. 회의 메모

다음 회의는 금요일 오후 2시. 회의자료는 내일 12시까지 드라이브에 올리기로 했다. 발표 리허설 시간은 아직 정하지 못했다.

최근 메모
귤메모 체험하기
  1. 웹 쓰는 중: 지금처럼 브라우저를 쓰면 귤 캐릭터만 남아요. 캐릭터를 누르면 책갈피가 나와요.
  2. 바탕화면: 브라우저 창의 ─를 누르거나 빈 바탕화면을 누르면 책갈피가 모두 펼쳐져요.
  3. 화면 끝: 화면 왼쪽 끝(점선 띠)에 마우스를 대면 최근 메모가 나와요. 휠로 넘기고, 떼면 사라져요.
  4. 사진: 메모를 열고 사진 버튼으로 내 파일에서 골라 넣어요. 사진을 끌어다 놓거나 붙여넣어도 돼요.
  5. 내 캐릭터: 캐릭터를 우클릭 → 설정 → 내 사진으로를 고르면 배경을 지워 캐릭터로 만들어요.
