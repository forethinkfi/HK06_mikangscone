# PCpet · 먹고자 데스크톱 펫

[Pety / Window Pet](https://github.com/Gavin-Dementia/Pety)의 MIT 엔진을 기반으로 한 개인용 커스터마이징 프로젝트입니다. 원본 LICENSE와 자산 라이선스 안내를 유지합니다.

## 시작

현재 적용한 방향별 도트 애니메이션은 기본 설치 후 `npm run setup:directional`로 연결합니다. [PMDCollab SpriteCollab](https://github.com/PMDCollab/SpriteCollab)의 원본 게임 스프라이트(CHUNSOFT, 각 캐릭터 `pmd/credits.txt` 참조)를 개인 폴더로 받습니다. 이미지 자체는 저장소에 올리지 않으며 엔진 MIT와 별개입니다. 좌우 이동에는 해당 옆모습, 벽을 올라갈 때는 뒷모습, 내려올 때는 앞모습을 사용합니다. 원본 그림은 `species-illustration-backup.json` 설정과 함께 남겨둡니다.

`sourceFrames`는 방향(아래·오른쪽 아래·오른쪽·오른쪽 위·위·왼쪽 위·왼쪽·왼쪽 아래)별 프레임의 실제 그림 영역입니다. 원본 이미지를 편집하지 않고 이 영역을 재생합니다. `pixelArt: true`는 도트가 번지지 않게 그리며 `displaySize`는 이동 영역 크기, `spriteScale`은 픽셀 확대 배율입니다.

Node.js 22 이상에서:

```sh
npm install
npm run setup:munchlax
npm start
```

설치 후 `먹고자 실행.cmd`를 더블클릭해도 됩니다. 펫을 잡아 이동하거나 클릭해 반응을 보세요. 작업 표시줄 알림 영역의 펫 아이콘 메뉴에서 숨기기와 종료를 선택합니다.

## 여러 펫과 대화

펫은 화면 하단과 양옆을 잇는 U자 경로로만 이동합니다. 중앙으로 드래그해도 가장 가까운 바닥 또는 벽으로 붙습니다. 해상도·작업 표시줄 영역이 바뀌면 활동 범위도 맞춰집니다. 말풍선에 캐릭터 이름은 표시하지 않으며, 눈누에 소개된 동글체를 제작자 배포본과 OFL 라이선스로 포함합니다. 고배율 화면에서도 캔버스를 실제 픽셀 밀도에 맞춰 그립니다.

기본 친구는 먹고자와 고라파덕입니다. 각각 돌아다니고, 가까이 만나면 짧은 대화를 나눕니다. 시작 후 첫 인사를 하고 이후 3~6분 간격으로 위로나 회사원 드립을 띄웁니다. 말풍선은 화면에 글로만 표시하며 음성이나 외부 AI 연결은 사용하지 않습니다.

알림 영역 펫 아이콘에서 `지금 대화하기`, `말풍선 끄기 / 켜기`, `이미지·대사 폴더 열기`를 선택할 수 있습니다.

`personal-species/scene.json`에서 `pets`에 함께 띄울 캐릭터 폴더 이름을 적습니다. 각 캐릭터 폴더에 `species.json`과 이미지를 두면 됩니다. `chatter.solo`는 사용자에게 건네는 말, `chatter.dialogues`는 질문·답변 쌍입니다. `minIntervalSec` / `maxIntervalSec`는 자동 말 걸기 간격(초), `bubbleSec`는 표시 시간, `enabled`는 말풍선 사용 여부입니다. 대사와 기존 캐릭터 그림·설정은 저장하면 자동 반영됩니다. 새 캐릭터 폴더를 추가한 뒤에는 재실행하세요.

## 이미지 수정

기본 크기는 두 캐릭터 모두 약 114픽셀(`spriteScale: 0.24`)입니다. 한 번만 실행되며 같은 캐릭터 ID도 중복 표시하지 않습니다. 기본·걷기·쉬기·졸기·잡힘·반가워하기의 여섯 상태를 사용합니다. `effect`에 `rest`, `sleep`, `held`, `happy`를 지정하면 상태별 자세와 표시가 달라집니다. 원본 이미지는 그대로 두고 화면에서 변형합니다.

개인 이미지는 `personal-species/munchlax/`에 있습니다. `munchlax.png`를 교체하면 모든 상태에 반영됩니다. 기본 475 × 475 투명 PNG이며 약 114픽셀로 표시합니다. `species.json`에서 상태별 그림·프레임·배율·걷는 속도를 조절하세요. 폴더 안 `이미지 수정 안내.txt`에 예시를 정리했습니다. 저장 시 자동 반영됩니다.

기본 버전은 한 장의 일러스트에 호흡·뒤뚱거림·흔들림·클릭 반응을 적용합니다. 잠들 때 눈을 감는 등의 별도 포즈는 아직 없으며 상태별 시트를 추가할 수 있습니다. 현재 펫은 실행 시 마우스가 있는 모니터에서 활동합니다.

캐릭터 이미지는 Git에서 제외됩니다. 설정 예시는 `examples/munchlax/`에 있고, 설정 스크립트는 PokeAPI sprites의 이미지를 개인 폴더로 다운로드합니다. Pokémon 이미지 권리는 원권리자에게 있으며 MIT 코드 라이선스에 포함되지 않습니다.
