# 귤메모 (Mikang Memo)

바탕화면 가장자리에 책갈피처럼 붙어 있는 메모지 + AI 비서 캐릭터. Windows와 macOS에서 동작하는 Electron 앱입니다.

**[Windows 실행파일 바로 받기](https://github.com/forethinkfi/HK06_mikangscone/raw/refs/heads/main/MikangMemo-Windows.exe)** · Windows 64비트. 다운로드 폴더에서 약 196MB인 `MikangMemo-Windows.exe`를 더블클릭하면 설치 없이 실행돼요.

**macOS 다운로드** · [Apple Silicon (M 시리즈)](https://github.com/forethinkfi/HK06_mikangscone/raw/refs/heads/main/MikangMemo-macOS-AppleSilicon.dmg) · [Intel Mac](https://github.com/forethinkfi/HK06_mikangscone/raw/refs/heads/main/MikangMemo-macOS-Intel.dmg). `.dmg`를 열고 **Mikang Memo**를 응용 프로그램 폴더에 옮긴 뒤 실행하세요.

`main`의 앱 코드가 바뀌면 GitHub Actions가 세 파일을 다시 빌드하고 검증한 뒤 저장소 최상위 파일을 Git LFS로 갱신해요.

**앱을 실행하려면 위의 운영체제별 링크로 받으세요.** GitHub의 **Code → Download ZIP**에 들어 있는 1KB 크기의 `.exe`나 `.dmg`는 Git LFS 참조 파일이라 열 수 없어요. ZIP으로 받은 소스는 [개발용 실행 방법](#실행하기-개발용)을 따라 실행할 수 있어요. Windows 설치 파일은 **Actions → Build desktop app**에서도 받을 수 있어요.

## 이렇게 동작해요

| 상황 | 화면 |
| --- | --- |
| **앱을 켜면** | 마지막으로 선택한 펫이 바로 나타나요. 처음에는 까망이가 나와요. 펫을 숨겼다면 트레이의 `펫 소환하기`로 다시 부를 수 있어요. |
| **펫을 우클릭하면** | 화면 가장자리에 간단한 책갈피가 열려요. 다시 우클릭하면 열린 책갈피, 위젯, 메모가 접혀요. |
| **전체보기를 누르면** | 위젯이 열려요. 같은 버튼이 `간단히 보기`로 바뀌고, 누르면 책갈피로 돌아가요. |
| **마우스를 화면 왼쪽/오른쪽 끝에 대면** | 최근에 본 메모지가 살짝 나와요. 휠로 최근 메모 5개를 넘겨보고, 누르면 열려요. 마우스를 떼면 다시 사라져요. |
| **메모지를 열면** | 기본 메모에서 바로 작성할 수 있어요. `⋯` 또는 Pro 메모지 아래에서 AI 정리를 열 수 있어요. |

### 섹션 책갈피와 메모 모아보기

- **섹션(큰 책갈피)**: 책갈피는 메모마다 늘어나지 않고 `업무`, `생활`, `아이디어`처럼 큰 섹션으로 붙어요. 섹션을 누르면 그 안의 메모 책갈피들이 펼쳐지고, 메모를 누르면 메모지가 열려요. `섹션 추가`로 새 섹션을 만들고, 설정에서 이름·색을 바꾸거나 지울 수 있어요 (지워도 메모는 '분류 없음'으로 남아요).
- **분류 정하기**: 새 메모를 쓸 때 메모지 위쪽의 분류에서 섹션을 고르거나 그 자리에서 새 섹션을 만들어요. 고르지 않으면 메모를 접을 때 비서가 내용을 보고 알맞은 섹션에 넣어줘요.
- **전체보기 위젯**: 책갈피 맨 위의 `전체보기`를 누르면 날짜와 일정, 메모, AI 정리를 한 위젯에서 볼 수 있어요. `메모 모아보기`에서 제목·내용으로 검색하고 자주 보는 메모를 고정할 수 있어요. `선택`을 누르면 여러 메모를 골라 정리할 수 있어요.
- **주간 일정**: 날짜에 점이 있으면 그날 일정이 있어요. 날짜를 누르면 일정과 시간이 표시되고, `일정 관리`에서 다른 날짜와 알람 설정을 열 수 있어요.
- **위젯 편집**: 전체보기 위쪽의 `위젯 편집`에서 순서를 바꾸거나 위젯을 숨기고 다시 표시할 수 있어요. 배치는 다음 실행에도 유지돼요.
- **기본 메모**: 심플한 메모를 열어 작성하고 하단에서 서식과 사진을 넣을 수 있어요. `⋯`에서 분류, AI 정리, 스티커, 일정이 열려요.
- **Pro 미리보기**: 개발 실행의 설정에서 `Pro`를 선택하면 종이 스킨 6종과 사진으로 움직이는 펫 만들기를 사용할 수 있어요. 구독과 결제는 연결 전이에요.
- **움직이는 데스크톱 펫**: 잡고 있으면 몸을 살짝 버둥거려요. **설정 → AI 비서 · 데스크톱 펫**에서 캐릭터 그림을 누르면 AI 비서와 움직이는 펫이 함께 바뀌어요. 펫을 `Shift`를 누른 채 우클릭하면 캐릭터 변경, 펫 숨기기, 앱 종료 메뉴가 열려요. 이 메뉴에서 기본 제공 캐릭터를 고르면 해당 테마도 함께 적용돼요. 펫을 숨겼을 때는 전체보기에서도 다시 소환할 수 있어요. Pro 미리보기에서는 `내 사진으로` 고른 이미지도 움직이는 펫으로 쓸 수 있어요.
- **더블클릭**: 블록 공룡은 불을 뿜고, 까망이는 마우스를 쫓아요. 쫓는 까망이를 다시 더블클릭하면 숨고, 설정에서 다시 고르면 나와요. 문어비서는 위로 먹물을 뿜고, 테디 비서는 하트를 날려요.
- **걷기**: 펫은 바닥을 좌우로 걷다가 화면 끝에 닿으면 방향을 바꿔요.
- **AI 비서 메뉴**: 모아보기의 말풍선 버튼이나 트레이의 `AI 비서`에서 열 수 있어요.
- **디자인**: 미깡스콘 프로토타입의 크림색 종이와 세이지 색상, Pretendard를 적용했어요.

### AI 비서 (자동화)

- **날짜를 알아서 알람으로**: “내일 12시까지 회의자료 제출”이라고 쓰면 내일 날짜 12:00에 마감 알람이 잡히고, 1시간 전에 미리 알려줘요. (미리 알림 시간은 설정에서 변경)
- **메모를 접으면 자동 정리**: 내용을 고친 메모를 접으면 비서가 키워드·요점·일정을 정리하고 알람을 맞춰요.
- **비서에게 부탁하기**: AI 비서 메뉴에 “금요일 오후 3시 치과”처럼 쓰면 새 메모가 만들어지고 알람이 맞춰져요.
- **사진 넣기**: 메모지의 `사진` 버튼으로 파일에서 고르거나, 사진 파일을 화면 어디에든 끌어다 놓아요 (메모지·캐릭터·책갈피·모아보기의 메모 위에 놓으면 그 메모로). 붙여넣기(Ctrl/⌘+V)도 돼요. JPG·PNG·GIF(움직임 유지)·WebP·BMP·SVG·AVIF·TIFF·아이폰 HEIC까지 넣을 수 있어요 (메모당 6장). 사진을 누르면 크게 볼 수 있고, 스티커로 붙일 수도 있어요. Claude 키가 있으면 사진 속 포스터·공지의 날짜와 할 일도 읽어서 알람을 맞춰요.
- **날씨**: "오늘 날씨 어때?", "내일 비 와?", "부산 날씨"처럼 물으면 기온·비 올 확률을 알려주고 우산도 챙겨줘요 (기상청 단기예보, 운영 서버에 공공데이터포털 키 등록, 설정에서 기본 도시 변경).
- **아침 브리핑**: 매일 아침 처음 켜질 때 오늘 일정과 날씨를 말해줘요.
- **알람과 디데이**: 알람은 화면 아래에 표시돼요. 메모 하단에서 일정별로 디데이를 켤 수 있어요.
- **펫 일정 안내**: 가까워진 알람 일정을 걷는 펫이 말풍선으로 알려줘요. 설정에서 `펫 일정 안내`와 `아침 브리핑`을 각각 조절할 수 있어요.

캐릭터는 까망이, 블록 공룡, 문어비서, 테디 비서 중에서 고르거나, **내 사진**으로 만들 수 있어요. 사진을 고르면 배경을 자동으로 지우고(누끼) 스티커처럼 흰 테두리를 둘러 캐릭터로 만들어요. 배경이 단순한 사진일수록 잘 되고, 잘 안 되면 '동그랗게 자르기'를 고르면 돼요. 사진은 컴퓨터 밖으로 보내지 않아요. 이름도 바꿀 수 있어요.

## 웹에서 미리보기

설치 없이 브라우저에서 써볼 수 있는 미리보기를 만들 수 있어요. 실제 컴퓨터 화면(바탕화면 아이콘, 브라우저 창, 작업 표시줄) 예시 위에서 앱과 같은 화면 코드가 돌아가요.

```bash
npm run preview
```

`preview/mikang-preview.html`이 만들어져요. 미리보기에서는 브라우저 창을 쓰면 "웹 사용 중", 창을 내리거나 바탕화면을 누르면 "바탕화면"으로 바뀌고, 화면 왼쪽·오른쪽 끝의 점선 띠에 마우스를 대면 최근 메모가 나와요. claude.ai에서 열면 API 키 없이 Claude 정리도 동작해요.

## 실행하기 (개발용)

Node.js 22.12 이상이 필요해요.

```bash
npm install
```

```bash
npm start
```

모아보기 위젯을 펼친 상태로 시작하려면 `npm start -- --overview`를 실행하세요.

미리보기용 가짜 바탕화면 배경과 함께 띄우려면:

```bash
npm start -- --demo
```

날짜 인식 및 펫 모션 테스트:

```bash
npm test
```

## 설치 파일 만들기

각 운영체제에서 직접 만들 때:

```bash
npm run dist:win
```

```bash
npm run dist:mac
```

결과물은 `dist/` 폴더에 생겨요. Windows는 단독 실행 파일 `MikangMemo-Windows.exe`와 `.exe` 설치 파일, macOS는 `.dmg`가 만들어져요.

GitHub에서 자동으로 만들 수도 있어요: 저장소의 **Actions → Build desktop app → Run workflow**를 누르면 Windows·macOS 설치 파일이 아티팩트로 올라와요. `v0.2.0`처럼 `v`로 시작하는 태그를 올려도 실행돼요.

> macOS 파일은 임시 서명되어 있어요. Apple 공증 전 빌드라 첫 실행이 차단되면 [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

## AI 연결 (선택)

캐릭터 우클릭 또는 메뉴 막대/트레이 아이콘 → **설정 → AI 연결**에서 키를 붙여넣고 **저장**을 누르면, 바로 실제 서버에 연결해 키가 맞는지 확인해 줘요. 키는 이 컴퓨터에만 OS 키체인 기반으로 암호화해서 저장돼요.

| 키 | 쓰임 | 없으면 |
| --- | --- | --- |
| Claude API 키 | 메모 정리, 부탁하기 | 앱에 들어 있는 규칙 기반 정리로 키워드·날짜·알람을 잡아요 |

환경변수 `ANTHROPIC_API_KEY`로도 넣을 수 있어요.

## 운영체제별 참고

- **바탕화면 감지**
  - Windows: 맨 앞 창이 바탕화면(Progman/WorkerW)이면 책갈피 모드예요. 작업표시줄이나 시작 메뉴를 누를 때는 상태를 유지해요.
  - macOS: Finder가 맨 앞에 있으면 바탕화면으로 봐요. (Finder 창을 열어 둔 상태도 바탕화면으로 취급돼요.)
  - 원하는 대로 안 되면 트레이 메뉴 → **화면 모드**에서 `항상 책갈피` / `항상 캐릭터만`을 고를 수 있어요. 설정에서 “웹 브라우저를 쓸 때만 캐릭터” 모드도 고를 수 있어요.
- **macOS 권한**: 알림이 안 보이면 시스템 설정 → 알림에서 Mikang Memo를 허용하세요.
- **여러 모니터**: 주 모니터에 붙어요.
- **단축키**: `Ctrl/⌘+Shift+M` 책갈피 펼치기.
- **데이터 위치**: 설정 → 데이터 폴더 열기 (메모는 `data.json`).

## 구조

```
electron/
  main.js        투명 오버레이 창, 클릭 통과, 마우스 위치·가장자리 감지, 트레이, 알림, 단축키
  foreground.js  맨 앞 앱 감지 (Windows: PowerShell + user32 / macOS: lsappinfo)
  ai.js          Claude 메모 정리(JSON 구조화 출력)
  store.js       메모와 설정 저장, API 키 암호화
  preload.js     화면에 열어주는 기능 목록
src/
  index.html, styles.css, app.js   책갈피·메모지·캐릭터·미리보기·알람 화면
  parse.js       한국어 날짜/시간 인식 ("내일 12시까지", "다음주 월요일 오전 10시", "30분 뒤" …)
  characters.js  AI 비서 캐릭터 SVG
test/            날짜 인식 테스트
```

화면 전체를 덮는 투명한 창 하나에 모든 것을 그리고, 마우스가 책갈피·캐릭터·메모 위에 있을 때만 클릭을 받아요. 그 밖의 곳을 누르면 아래에 있는 창이 그대로 클릭돼요.

## 테마

설정 → **테마**에서 테마를 고르면 색·글꼴·메모지·AI 비서 캐릭터·데스크톱 펫이 함께 바뀌어요. 팀원마다 테마를 하나씩 맡아 `src/themes/<이름>/`에 만들어요 — 방법은 [hk06-docs/docs/THEMES.md](hk06-docs/docs/THEMES.md).

- **파스텔** (진현주): 마스킹 테이프로 붙인 종이 메모지(둥근 사각·반듯한 사각·찢은 종이·찢은 줄노트·겹친 종이·모서리 테이프), 메모지 색 5가지(하늘·라벤더·크림·벚꽃·민트), 말랑 문어비서, 메모먼트 꾹꾹체(컴퓨터에 설치되어 있을 때).
- **모노 스케치** (mikangscone): 밝은 테마와 다크 테마, 스케치 메모지 6가지, 까망이, Pretendard.
- **빈티지 크래프트**: 올리브색과 빛바랜 잉크, 크래프트 메모지, 테디 비서, 고운돋움과 Gaegu.
- **블록 장난감**: 색색의 블록 모양 책갈피와 위젯, 블록 공룡, Mona12.
