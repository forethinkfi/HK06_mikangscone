# 귤메모 (Mikang Memo)

바탕화면 가장자리에 책갈피처럼 붙어 있는 메모지 + AI 비서 캐릭터. Windows와 macOS에서 동작하는 Electron 앱입니다.

## 이렇게 동작해요

| 상황 | 화면 |
| --- | --- |
| **바탕화면이 보일 때** | 화면 가장자리에 키워드 책갈피가 모두 펼쳐져 있어요. |
| **다른 앱·웹을 쓸 때** | 책갈피는 숨고 고른 **캐릭터(AI 비서)만** 남아요. 화면을 가리지 않아요. |
| **캐릭터를 누르면** | 책갈피가 펼쳐지고, 한 번 더 누르면 접혀요. 캐릭터 옆 말풍선 버튼(또는 우클릭)은 비서 메뉴(부탁하기 · 날씨 · 녹음 메모 · 일정 · 모아보기 · 설정)예요. |
| **마우스를 화면 왼쪽/오른쪽 끝에 대면** | 최근에 본 메모지가 살짝 나와요. 휠로 최근 메모 5개를 넘겨보고, 누르면 열려요. 마우스를 떼면 다시 사라져요. |
| **메모지를 열면** | 메모지 위에 캐릭터가 앉아 있어요. 캐릭터를 누르면 AI 정리를 해줘요. |

### 섹션 책갈피와 메모 모아보기

- **섹션(큰 책갈피)**: 책갈피는 메모마다 늘어나지 않고 `업무`, `생활`, `아이디어`처럼 큰 섹션으로 붙어요. 섹션을 누르면 그 안의 메모 책갈피들이 펼쳐지고, 메모를 누르면 메모지가 열려요. `섹션 추가`로 새 섹션을 만들고, 설정에서 이름·색을 바꾸거나 지울 수 있어요 (지워도 메모는 '분류 없음'으로 남아요).
- **분류 정하기**: 새 메모를 쓸 때 메모지 위쪽의 분류에서 섹션을 고르거나 그 자리에서 새 섹션을 만들어요. 고르지 않으면 메모를 접을 때 비서가 내용을 보고 알맞은 섹션에 넣어줘요.
- **메모 모아보기 위젯**: 화면 위에 항상 떠 있는 `메모 모아보기`를 누르면 코르크 보드에 모든 메모가 섹션별로 붙어 있어요. 맨 위에 전체 요약이 있고, `AI로 전체 요약`을 누르면 Claude가 급한 일·마감 위주로 정리해 줘요. 메모를 누르면 그 메모지로 넘어가요.

### AI 비서 (자동화)

- **녹음 → 메모**: 메모지의 `녹음` 버튼(또는 `Ctrl/⌘+Shift+R`)으로 녹음하면, 받아쓰기 → 비서가 정리 → 메모에 날짜와 함께 입력돼요.
- **날짜를 알아서 알람으로**: “내일 12시까지 회의자료 제출”이라고 쓰면 내일 날짜 12:00에 마감 알람이 잡히고, 1시간 전에 미리 알려줘요. (미리 알림 시간은 설정에서 변경)
- **메모를 접으면 자동 정리**: 내용을 고친 메모를 접으면 비서가 키워드·요점·일정을 정리하고 알람을 맞춰요.
- **비서에게 부탁하기**: 캐릭터를 누르고 “금요일 오후 3시 치과”처럼 쓰거나 마이크 버튼으로 말하면 새 메모가 만들어지고 알람이 맞춰져요.
- **사진 넣기**: 메모지의 `사진` 버튼으로 파일에서 고르거나, 사진 파일을 화면 어디에든 끌어다 놓아요 (메모지·캐릭터·책갈피·모아보기의 메모 위에 놓으면 그 메모로). 붙여넣기(Ctrl/⌘+V)도 돼요. JPG·PNG·GIF(움직임 유지)·WebP·BMP·SVG·AVIF·TIFF·아이폰 HEIC까지 넣을 수 있어요 (메모당 6장). 사진을 누르면 크게 볼 수 있고, 스티커로 붙일 수도 있어요. Claude 키가 있으면 사진 속 포스터·공지의 날짜와 할 일도 읽어서 알람을 맞춰요.
- **날씨**: "오늘 날씨 어때?", "내일 비 와?", "부산 날씨"처럼 물으면 기온·비 올 확률을 알려주고 우산도 챙겨줘요 (Open-Meteo, 키 필요 없음, 설정에서 기본 지역 변경).
- **아침 브리핑**: 매일 아침 처음 켜질 때 오늘 일정과 날씨를 말해줘요.
- **알람**: 운영체제 알림(Windows 알림 센터 / macOS 알림) + 캐릭터 말풍선 + 책갈피 흔들림으로 알려줘요. `10분 뒤 다시`도 돼요.

캐릭터는 귤비서 · 냥비서 · 토비서 · 구름비서 중에서 고르거나, **내 사진**으로 만들 수 있어요. 사진을 고르면 배경을 자동으로 지우고(누끼) 스티커처럼 흰 테두리를 둘러 캐릭터로 만들어요. 배경이 단순한 사진일수록 잘 되고, 잘 안 되면 '동그랗게 자르기'를 고르면 돼요. 사진은 컴퓨터 밖으로 보내지 않아요. 이름도 바꿀 수 있어요.

## 웹에서 미리보기

설치 없이 브라우저에서 써볼 수 있는 미리보기를 만들 수 있어요. 실제 컴퓨터 화면(바탕화면 아이콘, 브라우저 창, 작업 표시줄) 예시 위에서 앱과 같은 화면 코드가 돌아가요.

```bash
npm run preview
```

`preview/mikang-preview.html`이 만들어져요. 미리보기에서는 브라우저 창을 쓰면 "웹 사용 중", 창을 내리거나 바탕화면을 누르면 "바탕화면"으로 바뀌고, 화면 왼쪽·오른쪽 끝의 점선 띠에 마우스를 대면 최근 메모가 나와요. claude.ai에서 열면 API 키 없이 Claude 정리와 말로 하는 메모(받아쓰기)도 동작해요.

## 실행하기 (개발용)

Node.js 20 이상이 필요해요.

```bash
npm install
```

```bash
npm start
```

미리보기용 가짜 바탕화면 배경과 함께 띄우려면:

```bash
npm start -- --demo
```

날짜 인식 테스트:

```bash
npm test
```

## 설치 파일 만들기

각 운영체제에서 직접 만들 때:

```bash
npm run dist:win
```

```bash
npm run dist:mac
```

결과물은 `dist/` 폴더에 생겨요 (Windows는 `.exe` 설치 파일, macOS는 `.dmg`).

GitHub에서 자동으로 만들 수도 있어요: 저장소의 **Actions → Build desktop app → Run workflow**를 누르면 Windows·macOS 설치 파일이 아티팩트로 올라와요. `v0.2.0`처럼 `v`로 시작하는 태그를 올려도 실행돼요.

> macOS 설치 파일은 코드 서명이 되어 있지 않아서, 처음 열 때 앱을 **우클릭 → 열기**로 실행해야 해요. 정식 배포 시에는 Apple 개발자 인증서로 서명·공증하세요.

## AI 연결 (선택)

캐릭터 우클릭 또는 메뉴 막대/트레이 아이콘 → **설정 → AI 연결**에서 키를 붙여넣고 **저장**을 누르면, 바로 실제 서버에 연결해 키가 맞는지 확인해 줘요. 키는 이 컴퓨터에만 OS 키체인 기반으로 암호화해서 저장돼요.

| 키 | 쓰임 | 없으면 |
| --- | --- | --- |
| Claude API 키 | 메모 정리, 녹음 회의록 정리, 부탁하기 | 앱에 들어 있는 규칙 기반 정리로 키워드·날짜·알람을 잡아요 |
| OpenAI API 키 | 녹음 받아쓰기(음성 → 글) | 녹음 파일만 메모에 붙고 글로 바뀌지는 않아요 |

환경변수 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`로도 넣을 수 있어요.

## 운영체제별 참고

- **바탕화면 감지**
  - Windows: 맨 앞 창이 바탕화면(Progman/WorkerW)이면 책갈피 모드예요. 작업표시줄이나 시작 메뉴를 누를 때는 상태를 유지해요.
  - macOS: Finder가 맨 앞에 있으면 바탕화면으로 봐요. (Finder 창을 열어 둔 상태도 바탕화면으로 취급돼요.)
  - 원하는 대로 안 되면 트레이 메뉴 → **화면 모드**에서 `항상 책갈피` / `항상 캐릭터만`을 고를 수 있어요. 설정에서 “웹 브라우저를 쓸 때만 캐릭터” 모드도 고를 수 있어요.
- **macOS 권한**: 처음 녹음할 때 마이크 권한을 물어봐요. 알림이 안 보이면 시스템 설정 → 알림에서 Mikang Memo를 허용하세요.
- **여러 모니터**: 주 모니터에 붙어요.
- **단축키**: `Ctrl/⌘+Shift+M` 책갈피 펼치기 · `Ctrl/⌘+Shift+R` 녹음 메모.
- **데이터 위치**: 설정 → 데이터 폴더 열기 (메모는 `data.json`, 녹음은 `audio/` 폴더).

## 구조

```
electron/
  main.js        투명 오버레이 창, 클릭 통과, 마우스 위치·가장자리 감지, 트레이, 알림, 단축키
  foreground.js  맨 앞 앱 감지 (Windows: PowerShell + user32 / macOS: lsappinfo)
  ai.js          Claude 메모 정리(JSON 구조화 출력), OpenAI 받아쓰기
  store.js       메모·설정·녹음 파일 저장, API 키 암호화
  preload.js     화면에 열어주는 기능 목록
src/
  index.html, styles.css, app.js   책갈피·메모지·캐릭터·미리보기·녹음·알람 화면
  parse.js       한국어 날짜/시간 인식 ("내일 12시까지", "다음주 월요일 오전 10시", "30분 뒤" …)
  characters.js  AI 비서 캐릭터 SVG
test/            날짜 인식 테스트
```

화면 전체를 덮는 투명한 창 하나에 모든 것을 그리고, 마우스가 책갈피·캐릭터·메모 위에 있을 때만 클릭을 받아요. 그 밖의 곳을 누르면 아래에 있는 창이 그대로 클릭돼요.
